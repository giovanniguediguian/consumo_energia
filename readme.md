# Sistema para calcular o consumo e gasto de um aparelho eletrônico

O programa tem o objetivo de **calcular a média do consumo e do gasto** de qualquer aparelho eletrônico.

O código solicita a entrada de dados, onde é esperado que o usuário insira o **nome do aparelho, sua potência e o consumo diário**. Utilizando a **fórmula de conversão de watts para kWh**, o sistema finaliza exibindo a **média do consumo e do gasto mensal** desse aparelho.

Linguagem utilizada: Python
